## 4. 本批实施要点（F15，下一会话直接消费）

### 4.1 节点注册与 Host

- `NODE_TYPES` 含 `agent-task`；`registerMvpNodes` 注册并 freeze
- 端口：`context`(any 入)、`assets`(asset 入)、`out`(text 出)、`task`(text 出)
- `StudioNodeHost`：Agent 状态 chip 扩展（preparing/waiting_*/cancel_requested）；副标题走 `agentTaskSubtitle(config)`
- 文件：`studio-v2/src/features/canvas/nodes.tsx`、`registry.ts`

### 4.2 Config 形状（只存引用，不塞日志）

```ts
// studio-v2/src/features/canvas/agentTaskNode.ts
{
  agent_profile_id, skill_id?, instruction,
  active_task_id, latest_successful_task_id, session_id,
  result_summary?,   // ≤500 字短摘要
  task_history[]     // 有界 20，重跑时旧 active 推进
}
```

纯函数：`parse/validate/guide/canSubmit/patchAfterTaskSubmit/patchAfterTaskStatus/contextRefsFromIncomingEdges/agentTaskSubtitle`  
测试：`studio-v2/src/features/canvas/__tests__/agentTaskNode.test.ts`（12 测）

### 4.3 Inspector + 执行路径

- `AgentTaskInspector.tsx`：Agent/Skill/说明；`FieldLabel`/`SelectField`/`TextArea`（form.tsx）
- 执行：`createSession` → `createDockTask`（**复用 F14 dockApi**，第三套禁止）
- 连线上下文：`contextRefsFromIncomingEdges`（asset 有 version → asset 引用，否则 node）
- 查看结果：`openDock({ activeTaskId, sessionId, agentId, … })`
- 无 Agent：`EmptyState` → `/agents`
- 换 Agent 清 `skill_id`

### 4.4 画布级状态轮询（review 关键修复）

- `agentTaskRuntime.ts`：`refreshAgentTaskNodes` / `applyAgentTaskToNode` / `hasPollableAgentTaskNodes`
- `CanvasPage` 2s interval（loading 后）；**不依赖 Inspector 挂载**
- `getAgentTask` 抽到 `agents/api.ts`，`useAgentTask` 共用

### 4.5 Dock 接线补丁

- `dockStore.openDock` 支持 `activeTaskId` / `sessionId`（F15 查看结果入口）
- Dock 本身仍用 `useAgentTask(activeTaskId)` + events 轮询（F14 未改语义）

### 4.6 MVP 有意裁剪（Spec review 已记录，勿当回归）

- **无**完整 E2E 自动化（issue AC#6）；纯函数覆盖主逻辑
- **无** `artifact_ids` / 输出端口下游写出（与 F14「无 Artifact 表」一致；结果 = Dock 详情 + `result_summary`）
- **无** §15.4 `inputMapping` / `outputMode` / `autoRun`（输入靠边推导；手动点执行）
- Skill 可选：未绑定时轻提示，不阻塞执行

## 7. 实施层决策 / 裁剪（含本批）

- **UI 基线（硬性）**：语义色只用 `@theme` token；动效 transform/opacity、≤180ms；表单/空状态复用 `components/ui/form.tsx` + `empty-state.tsx`；禁 any；文件 **≤900 行**
- **F15 执行路径必须复用 dockApi**，禁止第三套 Task 创建
- **节点禁止**塞 messages/steps 全文；只存 ID + 短摘要
- **Runtime PATCH** 不可改 `executable_path` / `endpoint_url`（创建时写入）
- **React Flow**：`toRfNode` 必须回传 `selected`（F6 坑）
- **用户本地未提交内容勿动勿提交**：`static/*`、`API/.env`、`run.bat`、mac 脚本、`data/*`、`.scratch/`、`AGENTS.md`、`docs/agents/`、`.handoff/` 等
