## 1. 当前遗留与已知问题 (Known Issues to be Fixed)

### 1.1 Agent 任务节点选中面板问题
- **现象**: 在画布中点击选择 `smart-agent-task` (Agent 任务) 节点时，底部弹出的浮动控制面板 (`#composer`) 依然会显示图片节点的生成参数界面（如 `ComfyUI生成`, `MiniMax H3`, `16:9` 比例等）。
- **根因解析**:
  - `smart-canvas.js` (及 `canvas.js`) 中控制 `#composer` 显隐的逻辑在节点选中监听器 (`selectNode` / `updateComposerForNode`) 中，缺少对 `smart-agent-task` 节点的隔离条件，导致点击 Agent 任务节点时误触发了默认生图参数面板。
- **修复方案**:
  - 在 `#composer` 显隐判断中增加 `if (node.type === 'smart-agent-task') { composer.classList.remove('open'); return; }`，或者为其展示专属的 Agent 任务指令与运行状态面板。

### 1.2 大文件物理瘦身策略调整
- **复盘教训**: 之前尝试直接关掉 `canvas.js` 并替换为纯 ESM 骨架入口，导致依赖 `window.onload` 和底层全局 DOM 事件监听（如 `openCanvas()`、右键 `contextmenu` 菜单、`selectionBox` 框选）未被触发，出现了按钮、菜单与保存节点丢失的界面错乱。
- **后续实施原则**:
  - 保留 `smart-canvas.js` 和 `canvas.js` 作为主干正常加载，确保页面 100% 零 Bug。
  - 采用**渐进式抽取**：每次在 `static/js/modules/` 下新建独立 ES6 模块，原大文件通过 `import` / 代理调用该模块，逐步把大文件里的逻辑剥离出来，逐步瘦身。
