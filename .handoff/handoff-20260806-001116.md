## 1. 项目需求模板（一句话定位）

**Studio V2 个人版 MVP**：一个由全新 React UI 驱动的个人 AI 创作画布——复用现有 FastAPI 生成/画布能力，提供更好用的资产管理，并支持 Agent/Skill 管理与真实执行闭环。旧前端（`static/`）作为过渡期回退入口保留，新旧并行。

第一版四主线：
```
A. 新 React UI 与 React Flow 画布
B. 核心现有功能接入（图片/视频生成、ComfyUI、即梦、Codex Skill、上传/媒体、Provider/存储设置、Task Shelf、旧版回退）
C. 新资产库（Asset/AssetVersion/Tag/Collection + 回收站 + 画布拖放 + Agent 上下文）
D. Agent / Skill 管理与真实执行闭环（Runtime Probe、Skill 安装绑定、Agent Dock 任务、Artifact 保存）
```
明确延后：RunningHub、Midjourney、独立对话页、提示词库管理。

## 6. 环境与约定（重要）

- **Python 虚拟环境**：`.venv/`（Python 3.11.7）。所有 Python 测试/调试用 `.venv/Scripts/python.exe`（用户明确要求）。
- **后端**：`.venv/Scripts/python.exe main.py` → 端口 3888（`/api/*` 旧 + `/api/v2/*` 新）。V2 层在 `API/v2/`，main.py 仅挂载 10 行。
- **前端**：`studio-v2/`，`npm run dev` → 5173（proxy `/api`→3888）；`npx vitest run`（逻辑测试）；`npm run build`（tsc + vite）。
- **Vite dev 坑**：HMR 陈旧模块图会导致页面空白（`?t=` 缓存错误）——改多处文件后空白时**重启 dev server**，tsc 确认代码无误。
- **测试坑**：`tests/test_canvas_log_cleanup.py` 14 个失败是**预先存在的陈旧测试**（main.py 重构后 `delete_canvas_log` 等函数已删），与本项目无关，勿修；跑全量时 `--ignore`。
- **数据**：V2 SQLite 在 `data/studio-v2/studio.db`（自动建）；`data/projects.json` 新旧共享（V2 附加 revision/archived 字段，旧字段兼容）。冒烟数据（项目"冒烟项目"`prj_smoke`、画布 `cnv_f73c...`）保留在库中。
- **后端 TDD 约定**：新模块在 `API/v2/` 下独立文件 + `tests/test_v2_*.py`；校验错误**在端点内手动抛 V2Error**（勿注册全局 RequestValidationError handler，会覆盖 main.py 旧格式破坏旧接口）；ID 用 `db.new_id('前缀')`；时间 Epoch 毫秒。
- **前端约定**：业务状态进 Feature API 层 + TanStack Query（服务端）/ Zustand（编辑器）；组件不直接 fetch；节点类型表达业务能力不表达供应商；动效仅 transform/opacity、≤180ms、Reduced Motion 降级。
- **git**：用户工作区有大量未提交改动（`static/*.html`、mac 脚本等，用户本地内容，**勿动勿提交**）。`.scratch/`、`AGENTS.md`、`docs/agents/` 未提交（待用户决定）。
- **提交习惯**：每阶段一个 commit（`feat: ...`），implement 技能要求完成后提交。
