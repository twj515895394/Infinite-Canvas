## 1. 项目需求模板（一句话定位）

**Studio V2 个人版 MVP**：一个由全新 React UI 驱动的个人 AI 创作画布——复用现有 FastAPI 生成/画布能力，提供更好用的资产管理，并支持 Agent/Skill 管理与真实执行闭环。旧前端（`static/`）作为过渡期回退入口保留，新旧并行。

第一版四主线：
```
A. 新 React UI 与 React Flow 画布        （02/08/09 已完成）
B. 核心现有功能接入（图片/视频生成、ComfyUI、即梦、Codex Skill、上传/媒体、Provider/存储设置、Task Shelf、旧版回退）→ 本批 F7 后基本齐
C. 新资产库（Asset/AssetVersion/Tag/Collection + 回收站 + 画布拖放 + Agent 上下文）→ 后端 B5 + 前端 F11 已完成；拖放/自动入库待 F12
D. Agent / Skill 管理与真实执行闭环（Runtime Probe、Skill 安装绑定、Agent Dock 任务、Artifact 保存）→ 全部未做（阶段 6）
```
明确延后：RunningHub 专项、Midjourney、独立对话页、提示词库管理。

## 5. 实施层决策点 / 已记录裁剪（含本批新增）

- **v2 任务中心契约（扩展）**：`/api/v2/generation-tasks` 为统一任务中心：`POST ""`（图片）、`POST /comfy`（工作流）、`POST /video`（视频）。状态机 `queued→running→succeeded|failed|cancelled`（即梦 `jimeng_pending` 惰性续查）；取消优先 `_update_task` 守卫；容量上限 `TASKS_RETAIN_MAX=100`（`_trim_overfull_store` 三任务共享）；`AUTO_RUN` 测试开关。
- **执行复用边界（F7 新增）**：视频走旧 `canvas_video`（async 原生，长轮询在旧实现内，直接 `await`）；ComfyUI 走旧 `run_workflow`（同步函数 → `asyncio.to_thread`）；图片走 `build_online_image_result`。三者都是惰性 `from main import ...`（main.py 禁止新增代码）。
- **结果收敛（F7 新增）**：`normalize_video_result` 只保留 `{videos, video_items}` 稳定引用 + 参数回显，**上游 `raw`（供应商私有字段）一律不进任务视图**（与 F8 `normalize_comfy_result` 同契约）；时间戳 Epoch 毫秒。
- **Codex（F7）**：执行路径 = 图片节点 provider=codex → F6 图片任务既有 codex 分支（`generate_codex_provider_image`，需 GPT Image 2 helper）；`/api/codex/status` 探测 → 前端三态提示条（可用/缺 helper/未安装原因）。
- **节点结果引用（§3.5 落地）**：成功时仅把稳定引用写回 `config.result`（图片/工作流 `{urls,items}`，视频 `{videos,items}`），随画布持久化；节点缩略图 `resultUrls` 现为 `{url, kind}[]`，kind 随来源传递（视频走 `video` poster 语义，复用 `/api/media-preview` 视频首帧）。供 F12 消费。
- **UI 统一基线（本批新增，用户硬性要求）**：语义色只用 `@theme` token（`index.css`，白名单 bg/surface/surface-raised/surface-overlay/surface-subtle/border/border-strong/text/text-muted/text-faint/text-tertiary/accent/accent-strong/success/warning/danger/ink）；动效仅 transform/opacity、高频 ≤180ms、spring 一律 bounce:0、reduced-motion 降级；表单/空状态复用 `components/ui/form.tsx` + `empty-state.tsx`；禁内联类型断言读属性（用 `in`/`typeof` 收窄或守卫函数）。
- **vite 代理修复（本批）**：`/assets` 精确路径（含尾斜杠/查询串，正则 `^/assets\/?(\?|$)`）是 SPA 路由返回 index.html，`/assets/xxx` 才代理后端媒体。改 vite.config.ts 后需重启 dev server。
- **B5 已记录裁剪**（MVP §8.3）：无 Blob Store/物理去重/GC/Provenance 图谱；purge 硬引用仅扫画布节点。
- **F11 注意点**：后端列表默认不过滤 purged 记录（无 current_version），前端已降级为图标占位卡片；EditDialog 集合勾选为本地乐观更新（不读捕获快照）。
- **React Flow 坑（F6）**：节点 prop 更新会清空内部选择 → `toRfNode` 必须回传 `selected`。

## 6. 环境与约定（重要，含新增）

- **Python 虚拟环境**：`.venv/`（Python 3.11.7）。所有 Python 测试/调试用 `.venv/Scripts/python.exe`（用户明确要求）。
- **后端**：`.venv/Scripts/python.exe main.py` → 端口 3888（`/api/*` 旧 + `/api/v2/*` 新）。V2 层在 `API/v2/`，main.py 仅挂载 10 行。**main.py 是 19000 行历史文件：新代码禁止加进 main.py**（用户强调"太低级"），一律放 `API/v2/` 独立文件 + 惰性 `from main import ...`。
- **前端**：`studio-v2/`，`npm run dev` → 5173（proxy `/api`→3888，`/assets` bypass 见 §5）；`npx vitest run`（node 环境，纯逻辑测试）；`npm run build`（tsc + vite）。Windows 下 hub 启动用 `cmd.exe /c npm.cmd ...`；vite 8 默认绑定 `[::1]`。
- **代码规范（用户强调，强制）**：每个代码文件单一职责、**行数 ≤900 行**；新代码禁内联类型断言、禁 any、禁硬编码色值（用 token）。
- **Vite dev 坑**：HMR 陈旧模块图会导致行为异常——改多处文件或 vite.config 后**重启 dev server**。
- **测试坑**：`tests/test_canvas_log_cleanup.py` 失败是**预先存在的陈旧测试**，跑全量时 `--ignore`。新增：`tests/test_v2_generation_tasks.py`（12 例）、`test_v2_comfy_tasks.py`（14 例）、`test_v2_video_tasks.py`（10 例）。
