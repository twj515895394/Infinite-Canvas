### 2.3 关键 BUG 攻坚 — 画布空白处光标消失问题
- **根因发现**: 纠正了带有非法语法 `cursor: grab, move, default` 的单行 CSS 规则（CSS 关键字不可用逗号连接），并排查了 `#links` SVG 连线层与 `pointer-events: none` 继承擦除导致的鼠标指针隐形。
- **终极防护**: 在 [design-system.css](file:///t:/Infinite-Canvas/static/css/design-system.css) 底部注入高特异性光标守护层 (`#shell, #board, #world, #links, .world > svg.links`)，显式声明 `cursor: default !important` / `cursor: move !important`，确保指针在画布任何空白与连线区域 100% 正常显示。

## 3. 约定与维持的相关规范 (Conventions & Guardrails)

在接下来的开发中，后续代理与开发者需严格恪守以下规范：

1. **样式增补原则**：
   - 任何针对 UI 细节的样式调整，优先收口在 [design-system.css](file:///t:/Infinite-Canvas/static/css/design-system.css) 中，禁止直接在业务逻辑 JS 中硬编码行内 `style`（动态坐标与 Transform 除外）。
2. **光标与指针继承防线**：
   - 给画布组件或背景定义 cursor 时，绝不能写在同一行用逗号分隔多个关键字（如 `cursor: grab, move`）。必须遵循渐进增强的多重声明：
     ```css
     cursor: default !important;
     cursor: move !important;
     cursor: -webkit-grab !important;
     cursor: grab !important;
     ```
3. **CSS 代码优雅度**：
   - 保持一选择器一花括号的多行结构，避免恢复单行压缩规则，维护可读性。
