## 6. 实施层决策点 / 已记录裁剪（含本批新增）

- **F13 前端消费契约（本批新增，后端已实现）**：Runtimes Tab 用 `GET /agent-runtimes` + probe（`POST /{id}/probe` 同步返回）；Agents Tab 用 `GET /agent-profiles`（含 runtime_profile/current_revision/skill_bindings）+ duplicate/test；Skills Tab 用 `GET /skills`（summary 含 active_version/source_types/binding_count）+ discover/import（ZIP multipart）；Tasks Tab 用 `GET /agent-tasks?session_id=&status=` + events 轮询。404 码：AGENT_RUNTIME_NOT_FOUND/AGENT_PROFILE_NOT_FOUND/SKILL_NOT_FOUND/AGENT_SESSION_NOT_FOUND/AGENT_TASK_NOT_FOUND。
- **时间输出**：后端统一 Epoch 毫秒直出（与现有 v2 一致；设计文档的 ISO 8601 由前端格式化层承担，`features/assets/api.ts formatDate` 为既有模式）。**F13 需沿用此约定，勿引入 ISO 解析**。
- **Skill 导入**：ZIP multipart 字段名 `file`，Form 另有 `project_id`/`activate`；本地目录用 Form `path`。校验失败 422 SKILL_MANIFEST_INVALID / 400 SKILL_PACKAGE_INVALID；同版本 409 SKILL_VERSION_EXISTS。
- **Agent test / Skill test**：`POST /agent-profiles/{id}/test`（同步驱动 Task 到终态，返回 ok/message/task）；`POST /skills/{id}/test`（MVP 不执行脚本，返回 manifest+instructions_preview）。
- **Task 创建**：必须走 `POST /agent-sessions/{session_id}/tasks`（含 agent_profile_id/message/idempotency_key，可选 skill_id/context）；201 新建 / 200 复用（响应 `reused` 字段区分）。
- **UI 统一基线（F6 起沿用，硬性要求）**：语义色只用 `@theme` token；动效仅 transform/opacity ≤180ms、spring bounce:0、reduced-motion 降级；表单/空状态复用 `components/ui/form.tsx` + `empty-state.tsx`；禁内联类型断言读属性；文件 ≤900 行。
- **vite 代理**：`/assets` 精确路径是 SPA 路由，`/assets/xxx` 才代理后端媒体（vite.config.ts 已配 bypass）。改配置后重启 dev server。
- **B5 已记录裁剪**（MVP §8.3）：无 Blob Store/物理去重/GC/Provenance 图谱；purge 硬引用仅扫画布节点。
- **React Flow 坑（F6）**：节点 prop 更新会清空内部选择 → `toRfNode` 必须回传 `selected`。
