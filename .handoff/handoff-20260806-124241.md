## 4. 本批实施要点（F13/F14，下一会话直接消费）

### 4.1 F13 Agent Center

- 路由：`/agents` → `studio-v2/src/features/agents/AgentsPage.tsx`
- API 层：`features/agents/api.ts`（≤900 行）+ `status.ts`（标签/tone/formatValidationResult）
- 四 Tab：`components/{Agents,Skills,Runtimes,Tasks}Tab.tsx` + `StatusChip.tsx`
- 时间戳：Epoch 毫秒 + `formatDate`（勿引入 ISO 解析）
- Agents 展开区：绑定 Skill + Instructions + **近期 Task**（客户端按 `agent_profile.id` 过滤 `useAgentTasks`）
- Skills：discover / import ZIP|path / 版本 `validation_result` 展示 / 启停
- Runtimes：CRUD + Probe；**PATCH 不支持改 path/endpoint**（编辑 UI 禁用这两项）
- Tasks：状态筛选、详情、取消/重试、活跃 2s 轮询
- `client.ts`：FormData 不强制 JSON CT；`timeoutMs`（Agent test 120s）

### 4.2 F14 Agent Dock

- 全局浮层：`components/AgentDock.tsx`，**AppShell 挂载**
- 状态：`dockStore.ts`（Zustand：open/agent/skill/message/contextRefs/session/task/project/canvas）
- 执行 API：`dockApi.ts`  
  - `createSession` → `POST /api/v2/agent-sessions`  
  - `createDockTask` → `POST /api/v2/agent-sessions/{id}/tasks`（`buildTaskCreateBody`：selection_refs + attachment_asset_version_ids + idempotency_key）  
  - `useTaskEvents` → `GET /api/v2/agent-tasks/{id}/events?cursor=`（1.5s，活跃时）  
  - 结果：`saveResultToLibrary`（multipart ingest，**projectId**）/ `downloadResultFile`（txt|json）
- **入口**：
  - TopBar Bot → `openDock({ source: 'shell' })`
  - 画布工具条 Bot → 选中节点 `nodeToContextRef` + projectId/canvasId
  - 资产预览「使用 Agent」→ `assetToContextRef`
  - Agent Center 顶栏按钮
  - Dock 内「添加资产」多文件 upload → merge chips
- 取消：`cancel` 响应立刻 `setLiveStatus`；终态优先 `activeTask.status`
- 换 Agent：清 `skillId` / `sessionId` / **`activeTaskId`**
- 纯函数测试：`features/agents/__tests__/dock.test.ts`

### 4.3 关键契约（后端未变，前端已对齐）

- Task context：`selection_refs[]` 类型 `asset|node|canvas|project|artifact`；asset 需 `version_ref`（Pinned）
- 事件流：**轮询**非 SSE（MVP）；cursor = 已见消息 sequence
- 无独立 Artifact CRUD API；F14 用「文本/JSON 文件 → 资产库 ingest」+ 本地下载充当 Artifact
- 后端模块仍在 `API/v2/agent_*.py`；**禁止往 main.py 塞业务**

- **F14 Artifact**：无后端 Artifact 表写入；结果 = 资产库 document + 本地下载。若 F15 要「Artifact 引用端口」，优先复用 **asset_version_id / task_id**，勿新造半套 Blob

- **React Flow**：`toRfNode` 必须回传 `selected`（F6 坑）
- **用户本地未提交内容勿动勿提交**：`static/*`、`API/.env`、`run.bat`、mac 脚本、`data/*`、`.scratch/`、`AGENTS.md`、`docs/agents/` 等
