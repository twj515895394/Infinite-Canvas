## 1. 项目需求模板（一句话定位）

**Studio V2 个人版 MVP**：一个由全新 React UI 驱动的个人 AI 创作画布——复用现有 FastAPI 生成/画布能力，提供更好用的资产管理，并支持 Agent/Skill 管理与真实执行闭环。旧前端（`static/`）作为过渡期回退入口保留，新旧并行。

第一版四主线：
```
A. 新 React UI 与 React Flow 画布        （02/08/09 已完成）
B. 核心现有功能接入（图片/视频生成、ComfyUI、即梦、Codex Skill、上传/媒体、Provider/存储设置、Task Shelf、旧版回退）
C. 新资产库（Asset/AssetVersion/Tag/Collection + 回收站 + 画布拖放 + Agent 上下文）
D. Agent / Skill 管理与真实执行闭环（Runtime Probe、Skill 安装绑定、Agent Dock 任务、Artifact 保存）
```
明确延后：RunningHub 专项、Midjourney、独立对话页、提示词库管理。

## 6. 环境与约定（重要，含新增）

- **Python 虚拟环境**：`.venv/`（Python 3.11.7）。所有 Python 测试/调试用 `.venv/Scripts/python.exe`（用户明确要求）。
- **后端**：`.venv/Scripts/python.exe main.py` → 端口 3888（`/api/*` 旧 + `/api/v2/*` 新）。V2 层在 `API/v2/`，main.py 仅挂载 10 行。
- **前端**：`studio-v2/`，`npm run dev` → 5173（proxy `/api`→3888）；`npx vitest run`（node 环境，无 jsdom，仅纯逻辑测试）；`npm run build`（tsc + vite）。Windows 下 hub 启动需用 `npm.cmd` 而非 `npm`。
- **代码规范（用户本会话强调，强制）**：每个代码文件单一职责、**行数 ≤900 行**；历史代码豁免，**新代码必须严格遵守**。B5 按此拆分为 assets.py(路由)/asset_ingest.py(ingest)/asset_repo.py(仓储)/asset_collections.py(集合)。
- **Vite dev 坑**：HMR 陈旧模块图会导致页面空白（`?t=` 缓存错误）——改多处文件后空白时**重启 dev server**。
- **测试坑**：`tests/test_canvas_log_cleanup.py` 失败是**预先存在的陈旧测试**（main.py 重构后函数已删），跑全量时 `--ignore`。
- **数据**：V2 SQLite 在 `data/studio-v2/studio.db`（自动建，B5 六表已注册进 `BASE_SCHEMA`）；`data/projects.json` 新旧共享。assets 物理文件落 `assets/input`（与旧接口同目录）。
- **后端 TDD 约定**：新模块在 `API/v2/` 下独立文件 + `tests/test_v2_*.py`；校验错误**在端点内手动抛 V2Error**（勿注册全局 RequestValidationError handler）；ID 用 `db.new_id('前缀')`；时间 Epoch 毫秒；SQL 全参数化（排序走白名单）。
- **前端约定**：业务状态进 Feature API 层 + TanStack Query（服务端）/ Zustand（编辑器）；组件不直接 fetch；动效仅 transform/opacity、≤180ms；主题经 `data-theme`（index.css 已有 light token）、手动动效降级经 `html[data-motion='reduced']`。
